Assistente de Sistema PC

Monitore a integridade do seu hardware, placa de vídeo e logs do Windows em tempo real de forma proativa.

Baixar Assistente (.py)

Como rodar no PC:

  1. Instale o Python no seu Windows.
  2. Abra o terminal e instale os requisitos: pip install requests psutil.
  3. Execute o script baixado para iniciar o monitoramento.
